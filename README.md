# Кассетная дека Technics RSBX-828
Тема для [foobar2000](https://www.foobar2000.org), имитирующая кассетную деку Technics RSBX-828

Реализована на основе [foo_uie_wsh_panel_mod_plus](https://github.com/ttsping/foo_uie_wsh_panel_mod_plus) от [ttsping](https://github.com/ttsping)

Тема состоит из двух окон: 
- Кассетная дека в главном окне foobar2000
<img src="images/screenshot.jpg" width=100%>

- Панель управления в отдельном окне на основе [foo_dockable_panels](http://wiki.bowron.us/index.php/Foobar2000) от Christopher Bowron  

<img src="images/control_panel.jpg" width=100%>

### Управление

<img src="images/control.jpg" width=100%>

- 1 - Выход из foobar2000
- 2 - Меню foobar2000
- 3 - Свободно (mouse drag / mouse wheel)
- 4 - Перемещение по треку (mouse drag / mouse wheel)
- 5 - Переключение вида крышки
- 6 - Сброс счетчика на 0
- 7 - Переключение режима счетчика (прошло / осталось)
- 8 - Переключение Playback Order
- 9 - Переключение вида индикатора
- 10 - Переключение вида кассеты. Левая часть кнопки - предыдущая кассета, правая часть - следующая кассета (mouse click / mouse wheel)
